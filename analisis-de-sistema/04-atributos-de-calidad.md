# 04. Atributos de calidad

- **Disponibilidad:** operativo durante emergencias.
- **Rendimiento:** las alertas deben mostrarse rápidamente.
- **Seguridad:** proteger cuentas y funciones administrativas.
- **Usabilidad:** información clara y sencilla para la población.
- **Escalabilidad:** soportar crecimiento de usuarios y alertas.
- **Confiabilidad:** mantener información consistente y validada.
- **Mantenibilidad:** facilitar cambios y nuevas funcionalidades.
