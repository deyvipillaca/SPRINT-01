# 02. Historias del usuario

- **HU01:** Como ciudadano, quiero consultar las alertas vigentes para conocer si existe peligro en mi zona.
- **HU02:** Como ciudadano, quiero recibir una notificación cuando se registre una alerta.
- **HU03:** Como administrador, quiero registrar una alerta indicando tipo, nivel, ubicación y recomendaciones.
- **HU04:** Como administrador, quiero gestionar las zonas de riesgo.
- **HU05:** Como autoridad, quiero consultar datos de lluvias para apoyar decisiones.
- **HU06:** Como administrador, quiero actualizar el estado de una alerta.
