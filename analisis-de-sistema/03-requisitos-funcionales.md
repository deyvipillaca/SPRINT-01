# 03. Requisitos funcionales

- **RF01:** Registrar usuarios y administrar roles.
- **RF02:** Registrar, editar y eliminar alertas.
- **RF03:** Clasificar alertas por tipo de desastre.
- **RF04:** Mostrar el nivel de riesgo.
- **RF05:** Registrar la ubicación de zonas afectadas o en riesgo.
- **RF06:** Enviar notificaciones de alertas activas.
- **RF07:** Mostrar recomendaciones de prevención y respuesta.
- **RF08:** Consultar historial de alertas.
- **RF09:** Actualizar el estado de las alertas.
- **RF10:** Consultar información de lluvias y monitoreo.
