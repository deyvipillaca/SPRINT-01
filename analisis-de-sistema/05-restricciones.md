# 05. Restricciones

- El sistema debe funcionar como aplicación web.
- Las funciones administrativas requieren autenticación.
- Las alertas deben ser registradas por usuarios autorizados.
- Se debe considerar la ubicación geográfica de las zonas de riesgo.
- El sistema depende de fuentes de datos meteorológicos disponibles.
- Las notificaciones dependen de los servicios de comunicación.
- La información debe validarse antes de difundirse.
- Se deben considerar problemas de conectividad en zonas de Ayacucho.
